Reviewed on 2026-09-29. The source lists Piccolo, Flute, Clarinet, Oboe, Cor Anglais, Bassoon, and an Ensemble Patch. `Cor Anglais` maps through the existing alias to `english-horn`; `Ensemble Patch` is mapped to `woodwinds-ensemble` by curator decision.

## Normalization decisions

- `Expressive Longs (vib)` → `long` with `expressive` and `vibrato`.
- `Trills st` → `trills` with `minor-2nd`; `Trills wt` → `trills` with `wholetone`.
- `Marcato`, `Staccato`, `Staccatissimo`, `Runs`, and `Flutter Tongue` map to their existing canonical articulations.
- The run-direction source labels `up & down`, `up`, and `down` have no canonical variants, so the catalog records the supported `runs` relationship without a variant.
- `Ornaments`, `Plosives`, `Tongue Rams`, `Multi-phonics`, `Whistle Tones`, and `Sing & Play` map to the curator-approved `various` articulation. This applies only to the instruments explicitly marked for each technique by the source.
- Oboe and Cor Anglais use the shared basic articulation set by curator decision because the source names those instruments but does not provide their patch-level articulation breakdown.
- The Ensemble Patch uses the same basic set as an inferred relationship needed to represent the curator-approved `woodwinds-ensemble` mapping; the source does not provide an articulation breakdown for it.
